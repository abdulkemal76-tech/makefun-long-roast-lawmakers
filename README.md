# The Long Roast: Lawmakers and the File They Cannot Convert

Entry for the make.fun bounty
[The Long Roast: Lawmakers and the File They Cannot Convert](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7).

`main.py` (Python 3.13, stdlib only) writes one satirical sentence,
at most 320 characters, roasting lawmakers who would regulate AI,
crypto or the internet but cannot convert a file to PDF, to
`/output/entry.txt`.

Run it with:

```sh
python3 -P -s main.py
```

The sentence:

> The senator writing the AI Safety Act keeps a file on his desktop
> called FINAL_v7_ACTUALLY_FINAL.docx, and every morning at 8:15 his
> aide turns it into a PDF for him.
